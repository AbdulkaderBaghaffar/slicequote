# Placeholder model

`benchy.stl` is a web-optimized copy of the official **#3DBenchy** model.

- Source: <https://github.com/CreativeTools/3DBenchy/blob/master/Single-part/3DBenchy.stl>
- Designer: Daniel Norée / CreativeTools
- License: **CC0 1.0 Universal (public domain)** — released February 14, 2025
- Project: <https://www.3dbenchy.com/>

## Web optimization

The original 10.8 MB STL (225,706 triangles) was simplified to
**19,184 triangles / ~937 KB** using three.js `SimplifyModifier` for the
quote-page placeholder. It is used only as a sample preview; uploaded models
replace it.

## Usage in the app

`benchy.stl` is the priceable sample model in the quote viewport.
`benchy-hero.webp` is a transparent 915×868 render of the same CC0 model,
used on the landing page so the hero does not load a second WebGL scene.
